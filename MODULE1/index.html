What is React?

The One-Line Definition

React is an external library — a bundle of code that someone else wrote, which you load into your project so you don't have to build everything from scratch.

💡
External Library — code that lives outside your own files. You reference it and get all of its power for free. React was written and maintained by Meta (Facebook).

Why Two Libraries?

🤔
You might wonder: why do we load both react AND react-dom? Aren't they the same thing?
Library Purpose Used For
react The core engine. Contains the shared logic for building UI components, managing state, and the virtual DOM algorithm. Websites Mobile Apps
react-dom The web-specific bridge. Knows how to talk to the browser's real DOM. Takes React's output and puts it on a webpage. Websites only

The key insight: react is shared between all platforms. Only the renderer changes — react-dom for web, react-native for mobile. This is brilliant design!
03

Minimum React Setup

This is the absolute minimum code required to get React running in a browser. Every piece matters:

HTML + React (Minimum) 
<!DOCTYPE html>
<html>
  <head>
    <title>My React App</title>
    <!-- Load React core -->
    <script src="https://unpkg.com/react/umd/react.development.js"></script>
    <!-- Load ReactDOM (web renderer) -->
    <script src="https://unpkg.com/react-dom/umd/react-dom.development.js"></script>
  </head>
  <body>
    <!-- React mounts into this div -->
    <div id="js"></div>

    <script>
      // Step 1: grab the container element
      const container = document.querySelector('#js');

      // Step 2: create a React root inside it
      // Step 3: render something into that root
      ReactDOM.createRoot(container).render("WELCOME");
    </script>
  </body>
</html>

04

JSX vs JavaScript

JSX = HTML inside JavaScript

JSX lets you write what looks like HTML directly in your .js file. Under the hood, it's converted to regular JS automatically.

✨ JSX Way (easier)
// Write HTML-like syntax
const button = (
  <button>HELLO</button>
);
📜 Plain JS Way (harder)
// Must do it manually
const button =
  document.createElement('button');
button.innerHTML = 'HELLO';
✅
Both do the exact same thing. JSX is just a nicer way to write it — that's the whole point!
JSX is NOT real HTML
JSX is NOT a separate language
JSX compiles to plain JS
05

The Render Rule

⚠️
Critical rule: .render() can only accept ONE top-level element. You cannot pass it two or three separate elements!
❌ WRONG — Two separate elements
const button = <button>Click me</button>;
const para   = <p>Hello</p>;

// ❌ This FAILS — render takes only ONE value
ReactDOM.createRoot(container).render(button, para);

↓

The Fix: wrap everything in a <div>

✅ CORRECT — Wrapped in a div
// Wrap multiple elements in ONE container
const content = (
  <div>
    <button>Click me</button>
    <p>Hello</p>
  </div>
);

// ✅ Works — ONE root element passed in
ReactDOM.createRoot(container).render(content);

💡 What is a <div>?

A <div> is a container — it's completely invisible on screen but acts as a wrapper that holds multiple elements together. Think of it as a transparent box. By wrapping your elements in a div, they all become children of ONE parent — satisfying render's requirement.

06

Full Working Example

Putting it all together — a complete page with multiple elements using JSX and a div wrapper:

Full React Page 
<!DOCTYPE html>
<html>
  <head>
    <title>My First React App</title>
    <script src="react.development.js"></script>
    <script src="react-dom.development.js"></script>
    <script src="babel.min.js"></script>  <!-- converts JSX → JS -->
  </head>
  <body>
    <div id="js"></div>

    <script type="text/babel">
      const container = document.querySelector('#js');

      // A div wraps everything so render gets ONE element
      const content = (
        <div>
          <h1>Welcome to React!</h1>
          <button>Click Me</button>
          <p>Hello, world!</p>
        </div>
      );

      ReactDOM.createRoot(container).render(content);
    </script>
  </body>
</html>
📌
Note on Babel: Babel is a tool that converts JSX syntax into regular JavaScript that the browser understands. Without it, the browser won't know what <button> inside JS means. In real projects (like with Create React App or Vite), this is handled automatically.
